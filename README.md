# Auto-build of [gost-engine](https://github.com/gost-engine/engine)
Built and packed against last + previous major for Debian & AlmaLinux, Arch rolling.
## Installation
Take the latest package from [release](https://github.com/GauriSpears/gost-engine-package/releases) and:
### Debian:
apt-get install gost-engine[yourversion].deb
### Arch:
pacman -U gost-engine[yourversion].pkg.tar.zst
### Alma:
dnf install gost-engine[yourversion].rpm
